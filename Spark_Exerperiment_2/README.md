Sales Data Analysis using PySpark DataFrame API

Objective: Analyze sales data to find top products and revenue trends.

Key Concepts: DataFrames, SQL-like operations, aggregations.

Aim
To implement Sales Data Analysis using PySpark DataFrame API and perform data analytics operations such as:

•	Calculating total revenue by products and cities. 

•	Finding the top 5 best-selling products. 

•	Calculating month-over-month revenue growth. 

•	Identifying products with the highest average order value.
