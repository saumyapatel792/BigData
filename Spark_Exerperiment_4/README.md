ETL Pipeline with PySpark DataFrames

Aim

To design and implement a complete ETL (Extract, Transform, Load) pipeline using PySpark DataFrame API for processing sales data from multiple sources.

The objectives are:

•	Read data from multiple CSV files. 

•	Perform data transformation using DataFrame operations. 

•	Join customer, order, and product datasets. 

•	Calculate customer lifetime value. 

•	Rank customers based on spending. 

•	Apply window functions for running totals. 

•	Perform data quality checks. 

•	Create views for analytical queries. 

•	Save processed data for further analysis.
