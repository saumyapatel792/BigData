Objective: Count word frequencies in a text file.

Key Concepts: RDDs, transformations, actions, basic aggregations

Aim

To implement a Word Count program using PySpark RDDs and perform text analysis by:

•	Counting word frequencies. 

•	Filtering words with length greater than 3 characters. 

•	Finding the top 10 most frequent words. 

•	Removing common stop words.
