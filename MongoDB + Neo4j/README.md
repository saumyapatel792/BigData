# Neo4j Student-Course Graph Database

## Experiment Title
**Implementation of Student Learning Network using Neo4j Graph Database and Cypher Queries**

---

## Objective

The objective of this experiment is to understand the concepts of graph databases by creating and querying a student-course network using Neo4j. The experiment demonstrates how nodes, relationships, and properties can be used to represent connected data and perform graph-based analysis.

---

## Software Requirements

- Neo4j Desktop / Neo4j AuraDB
- Neo4j Browser
- Cypher Query Language

---

## Database Model

The graph database consists of two main node types:

### Nodes

### 1. Student Node

Represents students in the learning system.

**Properties:**
- id
- name
- email
