
Fraud Detection System using PySpark

Aim

To develop a Fraud Detection System using PySpark that performs feature engineering on transaction data and detects potentially fraudulent transactions using machine learning techniques.


Objective

•	Load transaction data. 

•	Perform feature engineering. 

•	Extract time-based and transaction-based features. 

•	Calculate rolling statistics. 

•	Detect fraudulent transactions using a machine learning model. 

•	Display suspicious transactions.
