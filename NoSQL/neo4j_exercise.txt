3. Basic Queries
--------------------------------------------------------

Query 1
MATCH (u:User)
RETURN u;

Output:
Displays all users.

--------------------------------------------------------

Query 2
MATCH (a:User {name:'Alice'})
RETURN a;

Output:
Alice's profile.

--------------------------------------------------------

Query 3
MATCH (a:User {name:'Alice'})-[:FOLLOWS]->(f:User)
RETURN a.name,f.name,f.city,f.interests;

Output:

Alice -> Bob
Alice -> Carol

--------------------------------------------------------

Query 4
MATCH (f:User)-[:FOLLOWS]->(a:User {name:'Alice'})
RETURN f.name,f.city;

Output:

Bob
Carol

--------------------------------------------------------

Query 5
MATCH (u:User {city:'NYC'})
RETURN u.name,u.interests;

Output:

Alice
Carol
Eve

--------------------------------------------------------

Query 6
MATCH (u:User)
WHERE 'tech' IN u.interests
RETURN u.name,u.city;

Output

Alice
Dave
Frank
