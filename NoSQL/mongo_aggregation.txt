MONGODB AGGREGATION EXERCISE

Database: ecommerceDB
Collection: orders

--------------------------------------------------------
1. Total Revenue by Category
--------------------------------------------------------

db.orders.aggregate([
  { $match: { status: "completed" } },
  { $unwind: "$items" },
  {
    $group: {
      _id: "$items.category",
      total_revenue: {
        $sum: { $multiply: ["$items.price", "$items.qty"] }
      },
      items_sold: { $sum: "$items.qty" }
    }
  },
  { $sort: { total_revenue: -1 } }
]);

Output

Electronics   Revenue: 1975   Items Sold: 8
Furniture     Revenue: 550    Items Sold: 3
Accessories   Revenue: 60     Items Sold: 2

--------------------------------------------------------
2. Average Order Value
--------------------------------------------------------

db.orders.aggregate([
  { $match: { status: "completed" } },
  { $unwind: "$items" },
  {
    $group: {
      _id: "$order_id",
      order_total: {
        $sum: {
          $multiply: ["$items.price", "$items.qty"]
        }
      }
    }
  },
  {
    $group: {
      _id: null,
      avg_order_value: { $avg: "$order_total" },
      max_order: { $max: "$order_total" },
      min_order: { $min: "$order_total" }
    }
  }
]);

Output

Average Order Value : 646.25
Maximum Order Value : 850
Minimum Order Value : 510

4. Why do we use $unwind before $group?

Answer:
The $unwind stage converts each element of an array into a separate document so that each item can be grouped and aggregated individually.
